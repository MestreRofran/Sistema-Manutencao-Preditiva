# Sistema de Manutenção Preditiva (Indústria 4.0)

## Objetivo
Sistema de Machine Learning desenvolvido para prever quebras mecânicas em equipamentos de um parque fabril, evitando paragens na linha de produção.

## Tecnologias Utilizadas
* Python 3
* Pandas, NumPy (Manipulação de dados)
* Scikit-Learn (Machine Learning)
* Matplotlib, Seaborn (Visualização)
* Imbalanced-Learn (Balanceamento de dados - SMOTE)

## Como Executar
1. Clone este repositório.
2. Instale as dependências: `pip install -r requirements.txt`
3. Crie uma pasta chamada `/data` na raiz do projeto e insira o ficheiro `.csv` da base de dados.
4. Execute o ficheiro `.ipynb` utilizando o Jupyter Notebook.
